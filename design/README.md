# Design — ConsertaTech Mobile

Esta área mantém a identidade visual do ConsertaTech e suas adaptações para dispositivos móveis.

## Manter

- identidade visual;
- logo;
- cores;
- tipografia;
- padrões de componentes.

## Adaptar para Mobile

- navegação por toque;
- tamanhos de telas;
- espaçamento e legibilidade;
- formulários;
- componentes próprios de Android;
- estados de carregamento, erro e sucesso.

Protótipos e materiais visuais devem ficar nas pastas correspondentes.
