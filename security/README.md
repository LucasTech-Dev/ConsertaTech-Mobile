# Segurança

A segurança do Mobile deve ser tratada em conjunto com o back-end e o banco.

## Regras básicas

- Nunca armazenar senhas, tokens, chaves ou credenciais no Git.
- Nunca colocar credenciais do banco dentro do APK.
- Operações sensíveis devem ser executadas pelo back-end.
- Validar entradas no aplicativo e no servidor.
- Aplicar autenticação e autorização nas APIs.
- Proteger tokens e dados sensíveis no dispositivo.
- Evitar exposição de dados pessoais em logs.
- Documentar decisões e alterações de segurança.

As políticas e checklists específicos serão adicionados durante a implementação.
