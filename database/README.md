# Banco de Dados

O ConsertaTech Mobile utiliza o mesmo banco de dados definido para o projeto ConsertaTech Web.

Esta pasta serve para documentação, schema, migrations, seeds e backups controlados.

## Regra

Não criar um banco separado apenas por causa do aplicativo mobile. Alterações de estrutura devem ser avaliadas considerando Web + Mobile.

Nunca versionar dados reais de clientes, credenciais ou segredos.
